# Epic 9 Retrospective: Velora Studio and USB

## Epic summary

- **Epic goal (declared, `_bmad-output/planning-artifacts/epics.md`, "Epic 9"):** A keyboardist edits their sounds from a computer screen (macOS, Windows, Linux) with Velora Studio over a single USB-C cable: live parameter editing with the Studio Knobs, adding timbres to empty parts, full Write to Velora flows with device scopes, setlist organisation, fast SFZ conversion on the PC, high-speed library transfers with space checks, full backups and restores, partial bundle exports/imports with collision policies, firmware updates, device diagnostics exports, and comprehensive WCAG 2.1 AA accessibility. ## Findings

### Aggregate views

1. **Complete Mac-first Velora Studio software stack delivered.** All 20 desktop application stories operate end-to-end against the local engine and bridge mock/services. Studio runs cleanly on macOS, loads fast, maintains zero-raw-color-literals design system rules, and passes all WCAG 2.1 AA accessibility contrast and landmark requirements.
   - Disposition: **accept**.
2. **Audio/engine safety during heavy desktop operations.** File staging for sound libraries, bundle imports, and firmware updates enforces chunk-based streaming with space checks, CRC/SHA verification, and atomic directory rename/unpacking. Firmware updates strictly respect device autonomy: the unit announces readiness on its display, and the user must confirm installation on the physical device action sheet (Studio never forces an installation).
   - Disposition: **accept**.
3. **Firmware staging cleanup and error handling.** Review triaged issues regarding partial upload drops, space exhaustion (`UPDATE_NO_SPACE`), and version-mismatch reconnection were verified and tested in `sysd_bridge_tests` and `firmware_update.test.js`.
   - Disposition: **accept**.
4. **Hardware gadget stories (9.1, 9.2, 9.3) blocked on dev board.** Stories 9.1–9.3 require physical OTG peripheral controllers. Their protocol framing (`ws_v1`) and bridge architecture were designed to be 100% compatible with the NCM virtual network interface once the device tree and gadget drivers are booted.
   - Disposition: **defer to hardware phase** (tracked as action item 1).

### Diff-scope review lenses

All 20 story specs feature documented Review Triage Logs. Rigorous cross-layer review identified and addressed edge cases including:
- Reconnection token expiration and multi-client pairing timeouts.
- Defensive handling of hostile or corrupt backup/import files without crashing.
- Live-edit revision conflict detection (`STALE_REVISION`).
- Proper ARIA landmarks, keyboard focus trapping, and screen-reader live announcements.

- Desktop JavaScript tests: 367/367 passed (100%).
- Rust Tauri backend unit tests: 53/53 passed (100%).
- C++ bridge tests (`sysd_bridge_tests`): 19/19 test cases passed (100%).
