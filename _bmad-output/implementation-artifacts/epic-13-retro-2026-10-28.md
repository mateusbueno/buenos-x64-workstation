## Findings

Each finding has a source; disposition is fix now / defer / accept.

### Aggregate views

1. **Reference corpus import blockers resolved.** The initial retro identified that 10 of 12 reference corpus libraries failed import due to `..` relative paths, FLAC samples, and missing opcodes.
   - Stories 13.12 (`a707940`), 13.13 (`3fff84c`), and 13.14 (`6b2aa08`) were designed, implemented, and verified.
   - Salamander Grand Piano V3 (1,121 regions, 693 MB native bundle), Steel Drum, Osiris, Scarypiano, etc. now import cleanly and render all null-test probes.
   - Disposition: **accept** (resolved by delivered stories).
2. **Corpus opcode histogram hides non-opcode blockers.** Resolved by commit `cee2c90` which classifies failures by specific reason (path escapes, sample format, unsupported values) with exact `file:line` examples.
   - Disposition: **accept** (resolved).
3. **Format minor churn: format minor 8 reached.** Format minor 8 encapsulates the region EQ and dedicated modulation extensions without breaking backward compatibility.
   - Disposition: **accept**.
4. **God-file growth.** `engine/core/src/sample_engine.cpp` and `formatlib/src/sfz_import.cpp` grew significantly across the epic.
   - Disposition: **defer** (tracked as action item 6; split by concern before next engine epic).
5. **Duplicated logic between paths.** Helpers for CC modulation, pan law, and SF2 vs SFZ import routines.
   - Disposition: **defer** (tracked as action item 6).
6. **Real-time safety and Linux toolchain CI.** Docker-check CI and Linux gcc / RTSan / TSan builds were restored in commit `9fd449b`.
   - Disposition: **accept** (resolved).
7. **CPU cost declarations.** Addressed in commit `dbd51fb` for macOS host. Dev board calibration on physical RK3588 target remains pending board availability.
   - Disposition: **defer** (tracked as action item 7).
