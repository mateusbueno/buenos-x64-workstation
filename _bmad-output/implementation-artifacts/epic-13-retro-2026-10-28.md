## Findings

Each finding has a source; disposition is fix now / defer / accept.

### Aggregate views

1. **Epic's own corpus ACs are unmet; only 2 of 12 corpus libraries import.** After 13.11, VSCO 2 CE (75/75) and Manthey Klaviano (153 regions) import; the other 10 do not. Source: 13.7, 13.8, 13.9 Auto Run Results; `tools/corpus/manifest.json` unchanged. Real blockers are mostly outside the epic's story list: sample paths with `..` (746/747 Sonatina files, all Meatbass/Bear Sax, 12/13 Weresax, Scarypiano, Osiris), FLAC samples (Salamander, Headroom), `delay`, `offset_random`, `sustain_cc`, `ampeg_release_shape`, velocity crossfades `xfin/xfout_lovel`, `width_oncc`, generic `lfoNN`/`egNN`, `rt_decay`, `amp_veltrack_oncc*`. Disposition: **fix now** (new stories, see actions 1-3).
2. **Corpus opcode histogram hides non-opcode blockers.** The 13.7/13.8/13.9 implementers each discovered `..` paths, FLAC samples or `unsupported_value` rules (e.g. `ampeg_dynamic=1` with `ampeg_*_oncc`) that the histogram does not count. Source: 13.7 Auto Run Result (Salamander FLAC), 13.8 (kamoepiano301), 13.9 (`..` paths). Disposition: **fix now** (action 4); also a process lesson: scope decisions based on opcode histograms alone mispredicted which stories unlock which libraries.
3. **Format minor churn: 8 minors in one epic** (minor 2 to 8: 13.3, 13.4, 13.5, 13.6, 13.7, 13.8, 13.9; every story added a table). Each bump forced edits to "newer minor" tests (`bundle_test`, `protected_test`, `install_test`, `install_service_test`); 13.8 fixed this with `kFormatMinor + 1`. Source: story specs 13-3 to 13-9; commits. Disposition: **accept** with a lesson (the extension-table approach worked and kept old bundles byte-identical, but a single "extensions" container would avoid per-story minor bumps).
4. **God-file growth.** `engine/core/src/sample_engine.cpp` 1200 -> 2260 lines and `formatlib/src/sfz_import.cpp` 630 -> 1860 lines over the epic (`git show 62b97ef:<file> | wc -l` vs `wc -l` at HEAD). Source: those files. Disposition: **defer** (action 6, split by concern before the next engine epic).
5. **Duplicated logic between paths.** Review layers repeatedly flagged copies: `voice_filter` vs `cc_mod_value` (13.8), `library_sf2` vs the SFZ import/report path (13.11), `pan_gains` helper vs inline pan law (13.5), the replay's copy of the engine's xorshift constants (13.10, guarded by a drift test). Source: Review Triage Logs of 13.8, 13.10, 13.11. Disposition: **defer** (action 6).
6. **Real-time safety unverified on the target toolchain.** The RealtimeSanitizer variants and Linux/gcc were never built for 13.2 to 13.11 because `tools/ci/docker-check.sh` has been broken since 13.2 by an LVGL API drift in `ui/src/adapters/drm_adapter.cpp` (not touched). The new voice-start paths (curve tables, `pow`/`sin`/`cos`, `cc_trigger`, filter, modulation) were checked only by the plain traffic tests. Source: 13.2 and 13.3 to 13.9 Auto Run Results. Disposition: **fix now** (action 5).
7. **CPU cost declarations not calibrated.** Declared voice costs grew: single filter measured 2.2 units against the declared 2; second filter 11 units declared engine-wide on the macOS host (about 27% less arbiter headroom); modulation 28 units worst case (measured 26.4 to 27.3). All host figures, none on the board. Source: 13.8 and 13.9 Auto Run Results, `engine/core/README.md`. Disposition: **defer** until board calibration (action 7).
