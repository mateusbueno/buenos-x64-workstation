Velora 73: Action Sheet

One raised card, {rounded.lg}, centred over the current surface dimmed to 35%, with an eyebrow, a title in {typography.modal-title}, an optional plain-facts line, and 2–4 action rows of at least 56 px. Every row pairs the physical control with its verb (WRITE · Install, EXIT · Later). The five variants share one anatomy; only the copy, the rows and the optional pairing code change. Each is drawn in the Stage theme and the Studio theme, then again with every label lengthened by 40% with accented capitals, and the user-content name replaced by ÁÇÊÕÑ Ação.

Note. Story 4.19 adopted this file as its base: variant 1 is the base anatomy, and variant 1b (Remove from Favorites) was added so both Favorites states are drawn. Library, pairing and install variants are refined in Story 5.18.

  • VALUE highlights. Turning VALUE moves the highlight between rows; the highlighted row has a 3 px accent border and a ▶ marker, never colour alone. Touch on a row highlights and confirms it.
  • WRITE confirms. WRITE acts on release on the highlighted row, whatever it is named. A row labelled EXIT is closed by EXIT, not by WRITE.
  • EXIT cancels. EXIT closes the sheet, one level back, and changes nothing. Nothing happens while a sheet is open except what the sheet offers; playing keys still sounds.
  • Never unprompted during performance. A sheet opens only from a player action (long press, tap on Missing library, a Settings entry). Missing library and updates never raise one by themselves; they use the Status Bar and the Part Strip.
  • Sound. Only Install update stops sound, says so first, and is started by the player. Every other variant says what still holds ("It stays silent. You can keep playing.", "Your sound is not affected.").
  • Voice. Plain facts, vocabulary Library / Timbre / Live Set / Part, actions paired with the control. Warn colour is paired with ! and the words "Missing library".

1 · Favorites (base anatomy)

Long press on a Result Tile (Library timbre or Setlist Browser Live Set). Rows: WRITE · ★ Add to Favorites (or Remove from Favorites when already starred), EXIT · Cancel. This is the base the other variants reuse unchanged.

1b · Remove from Favorites

Same long press on a Result Tile that already carries ★. The first row flips to WRITE · Remove from Favorites; EXIT · Cancel is unchanged, and the starred tile keeps its ★ behind the dim so the state is readable without colour. Anatomy, row heights and footer are identical to variant 1.

2 · Missing library

The player taps the Part Strip that says Missing library (or the Status Bar warn takeover). The part is already silent; the sheet only offers the way out. WRITE · Replace timbre opens the Library for that part, WRITE · Import starts Import, EXIT · Cancel closes the sheet and leaves the part silent.

Pseudo-localization +40% with ÁÇÊÕÑ Ação

3 · Remove library

Started by the player in Settings › Libraries. Names the library and states the consequence plainly: Live Sets that use it will show Missing library. The highlight starts on the safe row (EXIT · Cancel); VALUE moves it to Remove library, WRITE confirms.

Pseudo-localization +40% with ÁÇÊÕÑ Ação

4 · Pairing code

Started by the player in Settings › Computer › Pair new computer. The 6-digit code is shown in the tabular figure of the Live Set name size; Velora Studio shows a Studio Dialog to type it. WRITE · New code replaces it; EXIT · Cancel ends pairing. Sound is unaffected.

Pseudo-localization +40% with ÁÇÊÕÑ Ação

5 · Install update

Started by the player in Settings › System & Update. The one action that stops sound, and only because the player asked: "Sound stops until the Velora restarts." WRITE · Install, EXIT · Later. Progress continues on the Boot Screen layout (UPDATING TO 1.3).
