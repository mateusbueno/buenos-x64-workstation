Comportamentos que estas telas fixam:
  • Carregar outro setlist ou importar uma biblioteca nunca interrompe o som atual, e a importação roda em segundo plano.
  • Na Library, tocar no teclado faz uma pré-escuta do timbre destacado antes de confirmar.
  • O Write mostra o que mudou e pergunta o escopo: cena, Live Set inteira ou "salvar como novo".
  • Write hold (Settings › Display & Language, 0,3 a 1,0 s, padrão 0,5 s): o Write exige segurar o botão, o que protege contra toque acidental. O Panel guard faz o mesmo para LIVE SET ◀ ▶ (300 ms).
  • O boot termina no último som usado, e a tela de boot diz o que está restaurando.
