Velora Studio — Part Editor: Modeled Electric Piano Sound

The Part Editor adapts the Modeled Electric Piano parameters directly from the versioned parameter registry (desktop/src/params_registry.js). Reflows seamlessly across 4 columns (≥ 52em), 2 columns (≥ 30em), and 1 column (< 30em).

1 · Desktop Part Editor (Studio Light Theme)

2 · Unbound / Not-Available State (kEngineNotAvailable)

When an electric piano part is loaded on a unit where the physical modeling engine is not present, Velora Studio displays the inert fallback state: parameters are displayed as read-only, stored safely in the Live Set message, and tagged with an advisory explanation.
