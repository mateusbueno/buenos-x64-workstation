## 2. Integration steps ready to execute on delivery

1. Store delivered files under a versioned path in the repo (path to be chosen by the developer; none exists). Record versions.
2. Typeface: point the token generator at the licensed files; regenerate LVGL subsets at every token size (sizes in the 11.15 brief section 3 table); weights >= 400 for device UI; regenerate type tokens from the new metrics; update DESIGN.md; add the notice.
3. Studio: bundle fonts + license; regenerate CSS via the generator.
4. Icons: put the .icns/.ico/PNG set into the Studio build inputs; build on macOS, Windows, Linux; confirm no stand-in remains.
5. Boot: load delivered frames at 1024x600 in the Story 8.7 Boot Screen; static frame under Reduced motion; remove the stand-in boot wordmark.
6. QA: run the Story 10.8 pseudo-localization screenshot job (epics.md:6103-6122) with `ÁÇÊÕÑ Ação`, both themes, Large text on/off; it must fail on any clipping.
7. Dev board: measure font atlas against the UI memory budget (no number exists in the repo; the founder or developer must state it first), redraw timing against the previous baseline, and re-run the Story 8.10 boot-time budget (<= 10 s, epics.md:5141; AC epics.md:6621).
