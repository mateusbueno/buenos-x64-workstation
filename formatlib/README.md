# formatlib

Role: lossless block-indexed library bundle (Story 1.12) plus the SFZ-to-instrument-model layer (Story 1.13). Writer and reader for the container, identity minting (`bundle_id`, `library_id`, `instrument_key`), in-house SHA-256/SHA-1/UUIDv5, a small WAV loader that feeds the writer, the per-instrument region table, and the SFZ importer mapping (`velora_sfz`). Crypto, SF2, the librarian (`librarian/`) and streaming are out of scope.

Dependency rule: may link only libFLAC (found via CMake config, pkg-config or find_library; >= 1.4, target 1.5.0; library only, no flac/metaflac binaries), the vendored SFZ parser closure under `third_party/` (only for the separate `velora_sfz` target) and the C++ standard library. It must not include anything from `engine/core` (or `engine/host`), and `engine/core` must not depend on it.

Container (target `velora_format`, namespace `velora::format`):

- Layout: 128-byte header, manifest, index table, blocks; little-endian, strictly contiguous, `total_size` in the header makes any truncation a typed error.
- Every sample is cut into blocks of `kBlockFrames` (4096) frames; frame k lives in block `k / 4096`, so a seek decodes exactly one block (`BundleReader::read_block`, per-thread `BlockDecoder`). 16/24-bit PCM is coded per block as a self-contained libFLAC stream (verified by decode at write time); 32-bit float is stored raw. Mono/stereo, 44.1/48/88.2/96 kHz. No resampling or requantization.
- Index entry: offset, size, frames and SHA-256 of the stored block bytes (checked before decoding unless `ReaderOptions::verify_block_hash` is off). The manifest carries per-sample PCM SHA-256, so `verify_all()` is the bit-exact decode verify.
- Identity: `bundle_id` = SHA-256 of the manifest (which embeds the index hash, so it covers all content); `library_id` = vendor-assigned or UUIDv5 of a fingerprint of keys, formats and PCM hashes; `instrument_key` = normalized relative path, minted only by `BundleWriter::add_instrument`. Output is deterministic for a given libFLAC version (encoded frames, hence file bytes and `bundle_id`, may differ across libFLAC versions; PCM hashes, decoded PCM and `library_id` do not). Only the STREAMINFO metadata block is written (no VORBIS_COMMENT/padding). Names are not part of `library_id`.
- Versions: `kFormatVersion` = 2; the reader accepts N and N-1 (1 and 2) and rejects anything else with `Error::kUnsupportedVersion`. Version 2 adds, after each instrument's sample list in the manifest, a region table (`u32` count + fixed 96-byte records, layout in `src/layout.hpp`); version 1 bundles read with empty region tables, and the writer refuses regions for `WriterOptions::format_version == 1`. Zero-length samples are allowed.
- PCM exchange convention: interleaved `int32_t`; float32 is carried as its IEEE bit pattern.

Instrument model (`velora/format/instrument_model.hpp`): a `Region` holds sample index, key lo/hi/center, velocity lo/hi, transpose/tune/volume/pan, offset, `seq_length`/`seq_position`, `lorand`/`hirand`, loop mode/start/end and the `ampeg` envelope, plus `trigger` (attack/release). `BundleWriter::add_region` validates a region against its sample (`validate_region`); the reader validates the same invariants and reports `kCorruptManifest`. Regions are part of the manifest, hence of `bundle_id`. `BundleWriter::set_source_id(s)` mints `library_id` = UUIDv5 of SHA-256("velora.source.v1" || 0 || s) instead of the content fingerprint, so re-importing changed content of the same source keeps its `library_id` (the librarian uses the SFZ's canonical absolute path).

SFZ import (`velora/format/sfz_import.hpp`, target `velora_sfz`): `parse_sfz_file(path)` runs the vendored sfizz 1.2.3 parser (BSD-2-Clause; licenses and the exact file list in `THIRD_PARTY_NOTICES.md` and `_bmad-output/business/11-12-sfizz-license-check.md`, sources in `third_party/`, built as `velora_sfizz_parser`) and maps the supported subset: headers `<global> <master> <group> <region> <control>`; opcodes `lokey hikey key lovel hivel pitch_keycenter tune transpose volume pan offset seq_length seq_position lorand hirand loop_mode loop_start loop_end ampeg_delay|start|attack|hold|decay|sustain|release trigger sample default_path`, `#define`, `#include`. Anything else (opcodes, headers, values such as `trigger=legato`, generator samples) is an issue with file:line and the whole file is rejected; there is no partial result. It reads no audio.

Custom sources: `BundleReader::open_source` takes a `ByteSource` (`velora/format/byte_source.hpp`) so a host can back a reader with its own file-system port (used by the library resolver).

Tests: `format_hash_test`, `format_bundle_test` (round trips, seek, truncation and bit-flip sweeps, corruption, version 1 and 2, region table, identity), `format_wav_test`, `format_sfz_test` (opcode mapping, inheritance, unsupported constructs).
